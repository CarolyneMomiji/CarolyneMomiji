### 🤖 Compliance Document Review App — Capture the Flag Challenge

A month-long, graded, team-built AI-assisted compliance review platform for financial advisors and compliance officers, built during a Glynac intern hackathon.

**My role:** Backend, AI/data pipeline, and DevOps — [full write-up here](https://github.com/CarolyneMomiji/compliance-review-ctf-writeup)

* Built and deployed a full-stack app (**FastAPI**, **PostgreSQL/pgvector**, **Next.js**) covering document submission, an AI-assisted review workflow, and role-boundary enforcement checked at the API layer, not just the UI.
* Implemented a **privacy-preserving pipeline**: PII is masked in code *before* any text reaches an LLM or embedding call, and the masking is independently verifiable from the payload itself.
* Built the **retrieval layer** for rule lookup, disclosure-by-absence detection, and precedent search, with a retrieval-quality evaluation harness (precision/recall/F1) to validate rule/precedent matching.
* Designed and deployed **CI/CD** (GitHub Actions, deploy-on-merge to an Azure VM), including live incident response under a hard deadline — VM resource exhaustion, resizing, and CI regressions.
* Took ownership of the Jira backlog after teammates fell behind, closing 60+ tickets across backend, AI, DevOps, and frontend.

**Tech:** `FastAPI` `PostgreSQL` `pgvector` `Next.js` `Docker` `GitHub Actions` `Gemini (LLM + embeddings)` `Alembic` `pytest` `Playwright`
